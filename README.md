# Retail Sales Analysis with SQL, pandas and Excel

End-to-end data analysis project: raw data -> data quality checks -> cleaning -> SQL analysis -> Excel report and charts.

> **Data note:** the dataset is **synthetic** (generated by `generate_data.py` with a fixed random seed) so the project is
> reproducible and safe to share. Known errors are injected on purpose so the quality checks have real problems to find.
> The numbers below describe this simulated data, not a real company.

## Pipeline
| Step | Script | What it does |
|---|---|---|
| 1 | `generate_data.py` | Creates 4 raw tables (customers, products, orders, order items) with injected errors |
| 2 | `quality_checks.py` | Detects duplicates, missing values, invalid dates, negative quantities, orphan keys, inconsistent text |
| 3 | `clean_data.py` | Cleans the data with pandas and loads it into a SQLite database (`data/retail.db`) |
| 4 | `run_queries.py` | Runs the 9 SQL queries in `sql/queries.sql` and saves each result as CSV |
| 5 | `build_report.py` | Builds an Excel report (live formulas, native charts, pivot-style table) and PNG charts |

## SQL skills shown (`sql/queries.sql`)
SELECT, WHERE, JOIN (up to 3 tables), GROUP BY, subqueries, CASE, CTE and a window function (running total).
Written in standard SQL for SQLite; the same queries work on PostgreSQL with small date-function changes.

## Data quality results (raw data)
| Issue | Records |
|---|---|
| Duplicate order rows | 40 |
| Missing customer ID | 30 |
| Order dates in the future | 15 |
| Negative item quantity | 30 |
| Items pointing to a missing product | 20 |
| Inconsistent city text (case / spaces) | 60 |

## Key findings
See `reports/key_findings.md` (generated from the query results). Examples: Electronics gives about 64% of revenue,
December is the best month, and Dhaka has the highest revenue.

## Outputs
- `reports/retail_sales_report.xlsx` - Summary (formulas), Monthly Revenue (chart), Category (chart), City, Top Customers, Top Products, Payment Methods, City x Category (pivot), Data Quality
- `charts/*.png` - monthly revenue, category revenue, average order value by city
- `reports/sql_results/` - result of every SQL query

## Run
```bash
pip install -r requirements.txt
python generate_data.py && python quality_checks.py && python clean_data.py && python run_queries.py && python build_report.py
```
